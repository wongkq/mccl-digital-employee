# GPU环境探测器（子系统①）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `/mccl-run` 测试前加一道 GPU 环境门禁：新增 `bin/mccl-gpu-probe` 探测原语（复用 `gpu_health_check.sh` 作带宽/健康引擎，补占用检测与结构化 verdict）+ `mccl-prober` agent，三态 verdict 都不递增 attempt。

**Architecture:** 路线 A（包一层）：`bin/mccl-gpu-probe`（bash，纯函数可单测 + main 做远程编排）子进程调用 `gpu_health_check.sh`（在 NODE0 上 `--no-deploy` 跑，报告拉回本地解析），补占用（mx-smi 进程列表）与 bin 就绪核对，输出 `gpu-verdict.json`（三态 `READY`/`NOT_READY`/`error`）。`mccl-prober` agent 编排脚本、写人类可读 `gpu-preflight.md`、在脚本崩时兜底产出合法 verdict。`/mccl-run` 在 supervisor(dev)=PASS 后、tester 前插入门禁，主控只读 JSON 的 `verdict` 字段。

**Tech Stack:** Bash（探测脚本，纯函数源码可测）、Python3（JSON 安全生成 + env loader，已是依赖）、Markdown（agent/命令/参考）、Claude Code 的 agents/commands 机制。

## Global Constraints

以下约束适用于每个任务，值从 spec 逐字抄录：

- **不新增配置文件。** 拓扑/卡数/bin 路径/ssh opts 全取自 `mccl-env.json`（经 `bin/mccl-env-load.py`，raw 14 + 派生 7）；带宽阈值复用 `gpu_health_check.sh` 内置常量。req①"可指定命令/bin"通过调用参数 `--probe-cmd`/`--bin`（v1 预留）+ `--hosts` 覆盖满足，不落进配置文件。
- **探测器只读不改。** 不杀进程、不改文件、不重启节点；发现占用只上报。违反 ABORT（spec §3.2/§8，新增 safety 第9条）。
- **全量门禁 + 带宽按 run 缓存。** 默认 `--mode full`；带宽按 run 缓存（`--reuse-bw <run>/.bw-cache`），占用每轮重查。缓存失效：新 run 必重跑 / `--no-bw-cache` 强制重测。
- **占用判定：任一卡有进程即占用，全部卡须空闲。** 最严判定，v1 不做白名单/PID 过滤。
- **三态都不递增 attempt。** 门禁是环境问题不是代码问题，不烧开发重试预算。
- **主控解析契约：** 主控在流水线内只读 `gpu-verdict.json` 的 `verdict` 字段（`READY`/`NOT_READY`/`error`）；退出码（0/1/2）仅作脚本独立调用契约。脚本崩、JSON 缺失时由 `mccl-prober` agent 兜底写 `{"verdict":"error",...}`。
- **远程行为无法端到端验证。** 本仓库连不上远程节点，探测器的 mx-smi/带宽/占用远程执行只能验静态不变式 + 本地 mock 解析；真实环境验证推迟到拷入 MCCL 仓库后人工盯一轮（沿用现有 README"已知限制"）。
- **`gpu_health_check.sh` 是仓库根的未跟踪独立脚本**（含硬编码 IP/密码，未入 git；`check.sh` 不变式3 只扫已跟踪文件故当前通过）。包装脚本（跟踪的插件文件）不得含私网 IP/密码字面量，一律用 `$MCCL_*` 变量。定位它优先 `$REPO_ROOT/gpu_health_check.sh`，缺失则报 error，**不静默跳过带宽检查**。
- **偏离 spec 一处（机制细节，非需求）：** spec §4.1 写"子进程调用 `gpu_health_check.sh --hosts <MCCL_NODES> --no-deploy`"，但未点明执行位置。`--no-deploy` 会禁用 auto_deploy，若在本地（无 GPU）跑会直接失败。正确做法是 **scp 脚本到 NODE0、在 NODE0（有 GPU）上以 `--no-deploy` 跑**，报告拉回本地——这样 `--no-deploy` 才成立（NODE0 有 GPU 不需 auto_deploy，也不会递归）。本计划按此实现，与 spec 的 `--no-deploy` 字面一致、与"复用引擎"意图一致。
- **引号/分层纪律：** 远程命令一律 `ssh $MCCL_SSH_OPTS root@$host "..."`、输出重定向在 ssh 外面流回本地（沿用 `references/mccl-remote-ops.md` §0.5/§0.6）。`$MCCL_*` 在本地 eval loader 后已知，本地展开后再发给 ssh。

```bash
#!/usr/bin/env bash
# bin/mccl-gpu-probe - GPU 环境探测原语（MCCL数字员工 子系统①）
#
# 复用 gpu_health_check.sh 作带宽/健康引擎，补占用检测与结构化 verdict。
# 产物 gpu-verdict.json，三态 verdict: READY / NOT_READY / error。
# 只读不改：不杀进程、不改文件、不重启节点（references/mccl-safety.md 第9条）。
#
# 退出码（脚本独立调用契约；主控流水线内只读 gpu-verdict.json 的 verdict 字段）：
#   0 = READY, 1 = NOT_READY, 2 = error
#
# 纯函数（parse_health_stats/assemble_verdict/emit_json）可被 tests/ 源码加载单测，
# 不依赖远程与 mccl-env.json；main() 才做远程编排。
set -uo pipefail

# ===================== 纯函数（可单测，不碰远程/环境） =====================

# parse_health_stats <report_file>
# 解析 gpu_health_check.sh 的 health_report.txt 统计行。该脚本颜色变量是字面
# '\033[..m' 字符串（plain echo 非 -e），故先剥字面转义再剥真实 ESC。
# 输出 "FAIL=<n> ERROR=<n> WARN=<n> PASS=<n> TOTAL=<n>"（eval-able）；
# 文件缺失输出全 0 并返回 1。
parse_health_stats() {
  local report="$1"
  if [ ! -f "$report" ]; then
    echo "FAIL=0 ERROR=0 WARN=0 PASS=0 TOTAL=0"
    return 1
  fi
  local clean
  clean=$(sed -e 's/\\033\[[0-9;]*m//g' -e $'s/\x1b\\[[0-9;]*m//g' "$report")
  local total pass warn fail err
  total=$(printf '%s' "$clean" | grep -oP '总测试项:\s*\K[0-9]+' | tail -1)
  pass=$(printf '%s'  "$clean" | grep -oP '通过 \(优秀\):\s*\K[0-9]+' | tail -1)
  warn=$(printf '%s'  "$clean" | grep -oP '警告 \(偏低\):\s*\K[0-9]+' | tail -1)
  fail=$(printf '%s'  "$clean" | grep -oP '失败 \(异常\):\s*\K[0-9]+' | tail -1)
  err=$(printf '%s'   "$clean" | grep -oP '错误:\s*\K[0-9]+' | tail -1)
  echo "FAIL=${fail:-0} ERROR=${err:-0} WARN=${warn:-0} PASS=${pass:-0} TOTAL=${total:-0}"
  return 0
}

# assemble_verdict <fail> <error> <warn> <occupied_n> <topo_ok 0|1> <bins_ok 0|1>
# 输出 READY | NOT_READY。error 态不在本函数产出（脚本崩时由 mccl-prober agent 兜底）。
# WARN 不改变 verdict（仍 READY），由 main 记进 failures[]。
assemble_verdict() {
  local fail="$1" error="$2" warn="$3" occupied="$4" topo_ok="$5" bins_ok="$6"
  [ "$topo_ok" = "1" ] || { echo "NOT_READY"; return; }
  [ "$bins_ok" = "1" ] || { echo "NOT_READY"; return; }
  [ "${occupied:-0}" -gt 0 ] 2>/dev/null && { echo "NOT_READY"; return; }
  [ "${fail:-0}"  -gt 0 ] 2>/dev/null && { echo "NOT_READY"; return; }
  [ "${error:-0}" -gt 0 ] 2>/dev/null && { echo "NOT_READY"; return; }
  echo "READY"
}

# emit_json - 读环境变量 V_* 生成 gpu-verdict.json（python3 保证 JSON 合法）。
# 调用者（main / 兜底）须先 export 好 V_* 全集。
emit_json() {
  python3 - <<'PY'
import json, os
def g(k, d=""): return os.environ.get(k, d)
def b(k): return os.environ.get(k, "0") == "1"
def i(k):
    try: return int(os.environ.get(k, "0") or 0)
    except: return 0
try: hosts = json.loads(os.environ.get("V_HOSTS_JSON", "[]"))
except Exception: hosts = []
try: occ = json.loads(os.environ.get("V_OCC_JSON", "{}"))
except Exception: occ = {}
failures = [l for l in os.environ.get("V_FAILURES", "").splitlines() if l]
doc = {
  "verdict": g("V_VERDICT", "error"),
  "mode": g("V_MODE", "full"),
  "topology": {"nnodes": i("V_NNODES"), "gpus_per_node": i("V_GPUS"),
               "mode": g("V_TMODE", ""), "ok": b("V_TOPO_OK")},
  "hosts": hosts,
  "occupancy": occ,
  "bandwidth": {"cached": b("V_BW_CACHED"), "fail": i("V_BW_FAIL"), "error": i("V_BW_ERROR"),
                "warn": i("V_BW_WARN"), "report": g("V_BW_REPORT")},
  "bins": {"sym": {"ok": b("V_BINS_SYM")}, "asym": {"ok": b("V_BINS_ASYM")},
           "mpirun": {"ok": b("V_BINS_MPI")}},
  "failures": failures,
  "evidence": {"health_report": g("V_BW_REPORT", ""), "logs": g("V_EVIDENCE_LOGS", "")},
}
print(json.dumps(doc, ensure_ascii=False, indent=2))
PY
}

resolve_toolkit_root() {
  if [ -n "${CLAUDE_PLUGIN_ROOT:-}" ] && [ -f "${CLAUDE_PLUGIN_ROOT}/references/mccl-safety.md" ]; then
    echo "${CLAUDE_PLUGIN_ROOT}"; return 0
  fi
  local self_root
  self_root="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
  if [ -f "${self_root}/references/mccl-safety.md" ]; then
    echo "${self_root}"; return 0
  fi
  return 1
}

# load_env: 设 TOOLKIT_ROOT / REPO_ROOT，eval loader 拿到 $MCCL_*。
load_env() {
  local tk
  tk="$(resolve_toolkit_root)" || { echo "mccl-gpu-probe: 找不到 references/mccl-safety.md（工具包未装对位置）" >&2; return 1; }
  command -v python3 >/dev/null 2>&1 || { echo "mccl-gpu-probe: 需要 python3" >&2; return 1; }
  REPO_ROOT="$(git rev-parse --show-toplevel 2>/dev/null)" || { echo "mccl-gpu-probe: 不在 git 仓库内，无法定位 mccl-env.json" >&2; return 1; }
  eval "$(python3 "$tk/bin/mccl-env-load.py")" || return 1
  TOOLKIT_ROOT="$tk"
}

# ===================== 远程检查 =====================

# ssh_exec_read <host> <cmd> ：只读远程命令，输出流回本地。必须带 $MCCL_SSH_OPTS。
ssh_exec_read() {
  ssh $MCCL_SSH_OPTS "root@$1" "$2" 2>&1
}

# check_topology: 设 TOPO_OK/TOPO_MODE/TOPO_NNODES/TOPO_GPUS。判定同 mccl-tester 第2节。
check_topology() {
  TOPO_NNODES="$MCCL_NNODES"; TOPO_GPUS="$MCCL_GPUS_PER_NODE"
  TOPO_OK=0; TOPO_MODE="unsupported"
  if [ "${MCCL_NNODES:-0}" -eq 1 ] 2>/dev/null; then
    TOPO_MODE="single-node"; TOPO_OK=1
  elif { [ "${MCCL_NNODES:-0}" -eq 4 ] || [ "${MCCL_NNODES:-0}" -eq 8 ]; } 2>/dev/null \
       && [ "${MCCL_GPUS_PER_NODE:-0}" -eq 8 ] 2>/dev/null; then
    [ "${MCCL_NNODES:-0}" -eq 4 ] && TOPO_MODE="OAM32" || TOPO_MODE="OAM64"
    TOPO_OK=1
  fi
}

# check_bins: 在 NODE0 核对 perf bin / mpirun 可执行。设 BINS_SYM/ASYM/MPI (0|1)。
check_bins() {
  BINS_SYM=0; BINS_ASYM=0; BINS_MPI=0
  local out
  out=$(ssh_exec_read "$MCCL_NODE0_IP" \
    "test -x '$MCCL_PERF_BIN_SYM' && echo S; test -x '$MCCL_PERF_BIN_ASYM' && echo A; test -x '$MCCL_MPIRUN' && echo M") || out=""
  case "$out" in *S*) BINS_SYM=1;; esac
  case "$out" in *A*) BINS_ASYM=1;; esac
  case "$out" in *M*) BINS_MPI=1;; esac
}

# check_occupancy: 每机 mx-smi 进程列表，任一卡有进程即占用。设 OCC_ALL_FREE/OCC_JSON/OCC_N/OCC_FAILURES。
# mx-smi 输出假设含 "Processes:" 段（仿 nvidia-smi），有数据行=占用。远程格式需真实硬件校准（spec §7/§9.1）。
check_occupancy() {
  OCC_ALL_FREE=1; OCC_N=0; OCC_JSON='{"all_free":true,"occupied":[]}'; OCC_FAILURES=""
  local occ_arr="" host out procs
  for host in $MCCL_NODES; do
    out=$(ssh_exec_read "$host" "mx-smi 2>&1") || out=""
    procs=$(printf '%s' "$out" | sed -n '/Processes:/,$p' | grep -cE '^[[:space:]]+[0-9]+[[:space:]]+[0-9]' || true)
    if [ "${procs:-0}" -gt 0 ] 2>/dev/null; then
      OCC_ALL_FREE=0; OCC_N=$((OCC_N+1))
      occ_arr="$occ_arr{\"host\":\"$host\",\"procs\":[\"mx-smi 报告有进程\"]},"
      OCC_FAILURES="${OCC_FAILURES}${OCC_FAILURES:+$'\n'}$host GPU 有进程占用"
    fi
  done
  occ_arr="${occ_arr%,}"
  OCC_JSON="{\"all_free\":$([ $OCC_ALL_FREE -eq 1 ] && echo true || echo false),\"occupied\":[$occ_arr]}"
}

# run_bandwidth <cache_dir>: 在 NODE0 上跑 gpu_health_check.sh --no-deploy，拉回 health_report 解析。
# 命中缓存则复用。设 BW_FAIL/ERROR/WARN/PASS/TOTAL/CACHED/REPORT。返回 0=有报告，2=出错。
run_bandwidth() {
  local cache_dir="$1"
  local report="$cache_dir/health_report.txt"
  BW_FAIL=0; BW_ERROR=0; BW_WARN=0; BW_PASS=0; BW_TOTAL=0; BW_CACHED=0; BW_REPORT=""
  if [ -z "${NO_BW_CACHE:-}" ] && [ -f "$report" ]; then
    BW_CACHED=1; BW_REPORT="$report"
  else
    mkdir -p "$cache_dir"
    local ghc="$REPO_ROOT/gpu_health_check.sh"
    if [ ! -f "$ghc" ]; then
      echo "mccl-gpu-probe: gpu_health_check.sh 缺失：$ghc（不静默跳过带宽检查）" >&2
      return 2
    fi
    local nodes_csv; nodes_csv=$(echo $MCCL_NODES | tr ' ' ',')
    scp $MCCL_SSH_OPTS "$ghc" "root@$MCCL_NODE0_IP:/tmp/mccl_ghc.sh" >/dev/null 2>&1 || return 2
    ssh $MCCL_SSH_OPTS "root@$MCCL_NODE0_IP" "bash /tmp/mccl_ghc.sh --hosts '$nodes_csv' --no-deploy" \
      > "$cache_dir/ghc.out" 2>&1 || true
    local rdir
    rdir=$(ssh $MCCL_SSH_OPTS "root@$MCCL_NODE0_IP" "ls -td \$HOME/gpu_health_results_* 2>/dev/null | head -1") || rdir=""
    [ -n "$rdir" ] || return 2
    scp $MCCL_SSH_OPTS "root@$MCCL_NODE0_IP:$rdir/health_report.txt" "$report" >/dev/null 2>&1 || return 2
    BW_REPORT="$report"
  fi
  local s FAIL ERROR WARN PASS TOTAL
  s=$(parse_health_stats "$report") || return 2
  eval "$s"
  BW_FAIL=${FAIL:-0}; BW_ERROR=${ERROR:-0}; BW_WARN=${WARN:-0}; BW_PASS=${PASS:-0}; BW_TOTAL=${TOTAL:-0}
  return 0
}

# ===================== main =====================

emit_error_json() {  # <msg>：脚本自身出错时也写一份合法 error JSON（减少依赖 agent 兜底）
  export V_VERDICT=error V_MODE="${MODE_OUT:-full}" V_NNODES=0 V_GPUS=0 V_TMODE="" V_TOPO_OK=0
  export V_BW_FAIL=0 V_BW_ERROR=0 V_BW_WARN=0 V_BW_CACHED=0 V_BW_REPORT="" V_OCC_JSON='{"all_free":true,"occupied":[]}'
  export V_HOSTS_JSON="[]" V_BINS_SYM=0 V_BINS_ASYM=0 V_BINS_MPI=0 V_EVIDENCE_LOGS="" V_FAILURES="$1"
  if [ -n "${PROBE_OUT:-}" ]; then emit_json > "$PROBE_OUT"; else emit_json; fi
}

main() {
  local mode=full hosts="" reuse_bw="" no_bw_cache=0 probe_cmd="" bin_override="" out=""
  while [ $# -gt 0 ]; do
    case "$1" in
      --mode) mode="$2"; shift 2;;
      --hosts) hosts="$2"; shift 2;;
      --reuse-bw) reuse_bw="$2"; shift 2;;
      --no-bw-cache) no_bw_cache=1; shift;;
      --out) out="$2"; shift 2;;
      --probe-cmd) probe_cmd="$2"; shift 2;;
      --bin) bin_override="$2"; shift 2;;
      -h|--help) usage; exit 0;;
      *) echo "mccl-gpu-probe: 未知选项 $1" >&2; usage >&2; exit 2;;
    esac
  done
  NO_BW_CACHE=""; [ $no_bw_cache -eq 1 ] && NO_BW_CACHE=1
  MODE_OUT="$mode"; PROBE_OUT="$out"

  load_env || { emit_error_json "环境加载失败（mccl-env.json 缺失/不在 git 仓库/python3 缺）"; exit 2; }

  check_topology

  FAILURES=""
  add_failure() { FAILURES="${FAILURES}${FAILURES:+$'\n'}$1"; }

  local topo_ok_v=0 bins_ok_v=1 occ_n=0
  [ "$TOPO_OK" = "1" ] && topo_ok_v=1 || add_failure "拓扑不支持: nnodes=$MCCL_NNODES gpus=$MCCL_GPUS_PER_NODE（需 1节点 或 4/8节点×8卡）"

  check_bins || { emit_error_json "bin 就绪检查 ssh 失败（NODE0 不可达或密钥未配）"; exit 2; }
  [ "$BINS_SYM" = "1" ] && [ "$BINS_ASYM" = "1" ] && [ "$BINS_MPI" = "1" ] \
    || { bins_ok_v=0; add_failure "bin 未就绪: sym=$BINS_SYM asym=$BINS_ASYM mpirun=$BINS_MPI"; }

  check_occupancy || { emit_error_json "占用检查 ssh 失败"; exit 2; }
  occ_n="$OCC_N"
  [ -n "$OCC_FAILURES" ] && FAILURES="${FAILURES}${FAILURES:+$'\n'}$OCC_FAILURES"

  if [ "$mode" = "full" ]; then
    local bw_dir="${reuse_bw:-$REPO_ROOT/.gpu-probe-bw}"
    run_bandwidth "$bw_dir" || { emit_error_json "带宽检查失败（gpu_health_check.sh 不可用或拉回报告失败）"; exit 2; }
    [ "${BW_FAIL:-0}" -gt 0 ] 2>/dev/null && add_failure "带宽 FAIL=$BW_FAIL"
    [ "${BW_ERROR:-0}" -gt 0 ] 2>/dev/null && add_failure "带宽 ERROR=$BW_ERROR"
    [ "${BW_WARN:-0}" -gt 0 ] 2>/dev/null && add_failure "带宽告警 WARN=$BW_WARN（仍 READY，供人工收紧）"
  else
    BW_CACHED=0; BW_FAIL=0; BW_ERROR=0; BW_WARN=0; BW_REPORT=""
  fi

  local v
  v=$(assemble_verdict "${BW_FAIL:-0}" "${BW_ERROR:-0}" "${BW_WARN:-0}" "$occ_n" "$topo_ok_v" "$bins_ok_v")

  export V_VERDICT="$v" V_MODE="$MODE_OUT" V_NNODES="$MCCL_NNODES" V_GPUS="$MCCL_GPUS_PER_NODE"
  export V_TMODE="$TOPO_MODE" V_TOPO_OK="$topo_ok_v"
  export V_BW_FAIL="${BW_FAIL:-0}" V_BW_ERROR="${BW_ERROR:-0}" V_BW_WARN="${BW_WARN:-0}"
  export V_BW_CACHED="${BW_CACHED:-0}" V_BW_REPORT="${BW_REPORT:-}"
  export V_OCC_JSON="$OCC_JSON" V_HOSTS_JSON="[]" V_BINS_SYM="$BINS_SYM" V_BINS_ASYM="$BINS_ASYM" V_BINS_MPI="$BINS_MPI"
  export V_EVIDENCE_LOGS="" V_FAILURES="$FAILURES"
  if [ -n "$PROBE_OUT" ]; then emit_json > "$PROBE_OUT"; else emit_json; fi

  case "$v" in
    READY) exit 0;;
    NOT_READY) exit 1;;
    *) exit 2;;
  esac
}

if [ "${BASH_SOURCE[0]}" = "${0}" ]; then
  main "$@"
fi

## GPU环境门禁（mccl-prober）

`/mccl-run` 在 `mccl-supervisor(stage=dev)` 判 PASS 之后、`mccl-tester` 之前，会先跑一道 **GPU 环境门禁**：核对 GPU 是否真的存在、健康、空闲、带宽达标，再决定是否铺 32 卡测试。避免测试直接铺到 GPU 正忙或正在报错的节点上空跑一轮。

**怎么跑的**：`mccl-prober` 调 `bin/mccl-gpu-probe --mode full`，复用仓库根的 `gpu_health_check.sh` 作带宽/健康引擎（scp 到 NODE0 跑、报告拉回本地解析），补占用检测（mx-smi 进程列表，任一卡有进程即占用）与 bin 就绪核对，产出 `<run>/attempt-<N>/{gpu-preflight.md, gpu-verdict.json}`。带宽按 run 缓存（`<run>/.bw-cache/`，跨 attempt 复用），占用每轮重查。

**三态行为**（主控只读 `gpu-verdict.json` 的 `verdict` 字段）：

| verdict | 含义 | 主控动作 | 递增 attempt |

| READY | 全绿（带宽 WARN 仍算 READY，标告警） | 进 tester | 否 |
| NOT_READY | 占用/带宽FAIL/bin缺/拓扑不符 | 停，报告 failures，等环境 | 否 |
| error | 探测自身出错（ssh 不通/mxvs 缺/脚本崩） | 停，报告出错 | 否 |

**三态都不递增 attempt**——门禁是环境问题不是代码问题，不烧开发重试预算。

**已知限制**：
- 占用判定"有进程即占用"是最严判定。集群若有常驻监控/守护进程占某卡，门禁会恒 NOT_READY。预留白名单/PID 过滤作为未来收紧项，v1 不做。
- `gpu_health_check.sh` 是仓库根的未跟踪独立脚本（含内网信息，不入 git）。包装脚本 `bin/mccl-gpu-probe` 是跟踪的插件文件，不含任何私网 IP/密码，一律用 `$MCCL_*` 变量。

```
